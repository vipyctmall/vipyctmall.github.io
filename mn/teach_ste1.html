VIPYCTMALL ACCOUNT SETUP GUIDE

Бүртгэлийн дэлгэрэнгүй заавар

01 ACCOUNT REGISTRATION

Apply for a Personal Account

  • Enter the username you want to use.
  • Enter your last name, first name, ID number, country/region, email and mobile number.
  • Create a login password and enter it again for confirmation.
  • Create a payment password for purchases and enter it again for confirmation.
  • Accept the privacy policy, verify the information and select “Register”.
02 ACCOUNT LOGIN

Log In After Registration

  • Enter your personal username in the first field.
  • Enter your login password in the second field.
  • Verify both entries and select “Login”.
03 ACCOUNT DASHBOARD

Confirm the Account Dashboard

  • Confirm that the welcome message is displayed, indicating a successful login.
  • Locate Personal Information, Orders and Manage Addresses in the left menu.
  • Select Manage Addresses for the next step.
04 SHIPPING ADDRESS

Add a Shipping Address

  • Select Manage Addresses from the left menu.
  • Add an address and enter the recipient name, phone, email and ID information.
  • Choose the country/region and enter state/province, town/city, full address and postal code.
  • Set it as the default address when needed.
  • Verify the details and select “Save Address”.
